◆ publish()

void MQTT::publish ( const char * topic,
const char * payload,
bool retained )

Oeffentlicher Zugriff auf die zentrale Publish-Stelle (siehe MQTT.cpp, publishAndLog()) - fuer Module wie HaDiscovery, die eigene Topics publizieren, aber keinen direkten Zugriff auf den privaten PubSubClient dieser Datei haben sollen. topic ist der volle Topic-String (inkl. "gartenwasser/"- bzw. "homeassistant/"-Praefix), landet wie jeder andere Publish auch im Live-Log.

◆ requestMainCmd()

void MQTT::requestMainCmd ( bool on)

Startet/stoppt die Automatik-Sequenz genau wie ein main/cmd MQTT-Befehl (inkl. aller Publishes) - fuer lokale Ausloeser wie das Touch-UI, keine Sonderlogik gegenueber dem MQTT-Pfad.

◆ requestProgramSelect()

void MQTT::requestProgramSelect ( uint8_t programIndex)

Wendet Programm programIndex (1-basiert, 0 = keins/abwaehlen) an - identisch zu main/program/cmd, aber ohne MQTT-Umweg. Fuer die Touch-UI-Programme-Unterseite (Touch-UI-Neugestaltung, siehe docs/spec/13-touch-ui.md), die per </>-Buttons durch alle Programme blaettert.
