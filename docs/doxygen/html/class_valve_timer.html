Setzt die Restlaufzeit von Ventil index auf 0 - fuer ein Ventil, das innerhalb einer noch laufenden Automatik-Sequenz bereits durchgelaufen ist (nicht "armiert", sonst sieht es so aus, als waere es noch an der Reihe). ◆ tick()

uint8_t ValveTimer::tick ( uint8_t activeMask)
static

Zaehlt die Restlaufzeit aller Ventile herunter, deren Bit in activeMask gesetzt ist (Bit index = Ventil index ist eingeschaltet). Muss sekuendlich aufgerufen werden. Liefert eine Bitmaske der Ventile, deren Countdown in diesem Aufruf 0 erreicht hat.
